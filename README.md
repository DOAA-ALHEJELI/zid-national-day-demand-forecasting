# Zid Platform Case Study: Saudi National Day Demand Forecasting

A practical case study in collaboration with Beyond Experience and Zid, acting as a Machine Learning Specialist for an e-commerce merchant to solve the inventory and campaign timing challenges during the Saudi National Day season.

---

## Business Context and Objectives
During commercial seasons, merchants face a critical dilemma: underestimating demand leads to stockouts, while overestimating leads to unsold surplus. As a Machine Learning Specialist, the goal of this project is to analyze historical sales data to answer two key questions for the merchant:
1. How many units of each product should be stocked?
2. When is the optimal time to launch the promotional campaign?

---

## Acquired and Applied Skills
* Data Preparation and Preprocessing: Cleaning, transforming, and preparing raw datasets for modeling.
* Exploratory Data Analysis (EDA): Analyzing and visualizing data to discover temporal trends and seasonal patterns.
* Feature Engineering: Creating and extracting impactful features to improve predictive performance.
* Machine Learning Model Development: Building predictive models using RandomForestRegressor.
* Model Evaluation and Interpretation: Evaluating model performance using metrics like MAE and MAPE.
* Model Validation and Generalization: Ensuring model robustness and generalization to unseen data.
* Using Model Outputs for Decision Support: Translating model insights into actionable inventory and campaign decisions.

---

## Key Case Study Results
* Campaign Launch Date: September 3rd (based on detected demand surge onset).
* Model Accuracy (MAE): ~5.11 (outperforming the baseline model).
* Error Rate (MAPE): ~12%.
* Recommended Inventory: 7,984 units (including a 15% safety stock margin to prevent stockouts).
* Estimated Cost: SAR 195,573.
